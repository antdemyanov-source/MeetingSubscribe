# MeetingScribe — установка на новой машине (Windows)

Инструкция по разворачиванию приложения на другом компьютере.
Обновляется по мере развития приложения.

---

## Что понадобится

| Компонент | Зачем | Обязательно? |
|---|---|---|
| Windows 10/11 | целевая платформа | да |
| Python 3.12+ | среда выполнения | да |
| WebView2 Runtime | отрисовка интерфейса | обычно уже есть в Windows |
| ffmpeg | сжатие записей wav → ogg (~20× меньше места) | нет, но желательно |
| Claude Code CLI | формирование саммари | нет (или своя команда) |
| Интернет при первом запуске | автозагрузка модели Whisper (~1.6 ГБ) | да, один раз |

---

## Установка

### 1. Python

Скачайте Python 3.12+ с [python.org](https://www.python.org/downloads/), при установке
отметьте галочку **Add Python to PATH**.

### 2. Приложение

Скопируйте папку приложения (git clone или распакуйте архив), например в `C:\AI\MeetingScribe`.

### 3. Зависимости

В PowerShell из папки приложения:

```powershell
python -m venv venv
venv\Scripts\pip install -r requirements.txt
```

### 4. ffmpeg (желательно)

ffmpeg — утилита конвертации аудио. Приложение использует её только для сжатия
записей `audio.wav` (~600 МБ/час) в `audio.ogg` (~30 МБ/час). Без ffmpeg всё
работает, но записи занимают много места.

```powershell
winget install Gyan.FFmpeg
```

После установки перезапустите терминал/приложение. Проверка: `ffmpeg -version`.

### 5. Claude Code CLI (для кнопки «Саммари»)

Кнопка ✨ у записи формирует саммари командой из настроек
(раздел **Саммари** → «Команда формирования саммари»). По умолчанию используется
Claude Code CLI:

```powershell
npm install -g @anthropic-ai/claude-code
claude   # первый запуск — логин в аккаунт
```

Нет CLI или нужен другой инструмент — впишите свою команду в настройках,
плейсхолдер `{transcript}` заменяется путём к транскрипту. Без настроенной
команды приложение работает полностью, кроме кнопки саммари.

### 6. Ярлык на рабочий стол

```powershell
$ws = New-Object -ComObject WScript.Shell
$lnk = $ws.CreateShortcut("$([Environment]::GetFolderPath('Desktop'))\MeetingScribe.lnk")
$lnk.TargetPath = "C:\AI\MeetingScribe\venv\Scripts\pythonw.exe"
$lnk.Arguments = "-m meetingscribe"
$lnk.WorkingDirectory = "C:\AI\MeetingScribe"
$lnk.IconLocation = "C:\AI\MeetingScribe\assets\icon.ico"
$lnk.Save()
```

(путь `C:\AI\MeetingScribe` замените на свой, если отличается)

## Первый запуск — что настроить

Откройте настройки (⚙ в шапке):

1. **Звук** — выберите микрофон, нажмите «Тест», проверьте индикатор уровня.
2. **Транскрипция** — модель Whisper (рекомендуется `turbo`). Нажмите
   **«Скачать / обновить модель»**, чтобы загрузить её заранее (~1.6 ГБ) — иначе
   она скачается сама при первой транскрибации, и та займёт больше времени.
   Здесь же переключатель автотранскрибации после записи.
3. **Саммари** — проверьте команду CLI. **Промпт формата саммари** лежит в
   `.claude/commands/summary.md` — по умолчанию он настроен под конкретного
   пользователя: замените своим через «Загрузить из .md…» или отредактируйте
   («Открыть промпт»). Промпт отвечает только за текст саммари: привязка встречи
   к активности и создание задач выполняются отдельными системными инструкциями
   приложения (`meetingscribe/prompts/`) и включаются галками в этом же разделе —
   они работают с любым пользовательским промптом. Снятая галка отключает
   соответствующую вкладку в интерфейсе.
4. **Интеграции** — путь к Obsidian vault, если пользуетесь (иначе кнопки
   Obsidian просто неактивны).
5. **Общие** — папка для записей, скрытие личных встреч.

### Словарь контекста (важно для качества саммари)

Промпт саммари читает файл `recordings/context.md` — словарь для расшифровки:
люди, команды, системы, специфичные термины. Файл в этой поставке заполнен под
конкретную компанию — **создайте свой** по аналогичной структуре (или очистите):
разделы «люди», «системы», «термины и сленг транскрибации». Чем полнее словарь,
тем точнее саммари передаёт имена и термины.

## Обновление приложения

```powershell
git pull                                # или замените файлы новой версией
venv\Scripts\pip install -r requirements.txt
```

Модель Whisper обновляется кнопкой в настройках (Транскрипция → «Скачать /
обновить модель»).

## Если что-то не работает

- **Логи**: `logs/meetingscribe.log` — туда пишутся все ошибки, включая фоновые.
- **Белое/пустое окно**: не установлен WebView2 Runtime — поставьте
  [Evergreen Runtime от Microsoft](https://developer.microsoft.com/microsoft-edge/webview2/).
- **Откат на старый интерфейс**: в `config.json` поменяйте `"ui_backend": "web"`
  на `"tk"` — запустится классический Tkinter-UI.
- **Записи в wav, а не ogg**: не найден ffmpeg (см. шаг 4).
- **«Команда … не найдена» при саммари**: CLI не установлен или не в PATH —
  проверьте команду в настройках раздела «Саммари».
- **Микрофона нет в списке**: подключите устройство и перезапустите приложение.
