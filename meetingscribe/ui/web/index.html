Модель скачивается с HuggingFace автоматически при первой транскрибации; кнопка позволяет сделать это заранее или обновить уже скачанную. Прогресс — в статусной строке.
Если выключено, запись просто сохраняется со статусом «Загружено» — транскрибацию можно запустить позже кнопкой ▶ у записи.
Плейсхолдер {transcript} заменяется на путь к транскрипту. По умолчанию используется Claude Code CLI, но можно подставить любую команду.
При загрузке нового промпта прежний сохраняется рядом как summary.md.bak.
Эти шаги выполняются системными инструкциями приложения независимо от загруженного промпта. Снятая галка также делает соответствующую вкладку неактивной.
Если путь не указан, кнопки отправки в Obsidian у записей неактивны.
Смена папки применяется после сохранения; записи из старой папки не переносятся.
